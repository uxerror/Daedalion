# Credits, contributors and license

## Daedalion

Daedalion is an independent fork of Cogito by Philip Drobar and contributors. The [Daedalion repository](https://github.com/uxerror/Daedalion) carries the fork's changes, documentation and tests. The project license is in [LICENSE](../LICENSE) (Copyright (c) 2023 Phazorknight, Copyright (c) 2026 uxerror for Daedalion). The original wiki credits and its MIT notice follow. Individual asset licenses appear with the assets below.

Contributors
------------
* [Phazorknight](https://codeberg.org/Phazorknight) : original repo creator.
* [AC-Arcana](https://github.com/ac-arcana) : added DynamicFootstepSystem

#### Adapted Systems and Code

* Player controller is based on Like475's [First Person Controller Advanced](https://github.com/Like475/fpc-godot)
* Menus are based on SavoVuksan's [EasyMenus (also see this link for documentation)](https://github.com/SavoVuksan/EasyMenus)
* Inventory system was helped by following [DevLogLogan on Youtube](https://www.youtube.com/watch?v=V79YabQZC1s)
* [InputHelper by Nathan Hoad (also see this link for documentation)](https://github.com/nathanhoad/godot_input_helper)
* Bryce Dixon supplied Cogito's original audio plugin. [Original project credit](changelog.md#removed).
* Stairs handling based on [GodotStairs by elvisish](https://github.com/elvisish/GodotStairs)
* Cogito Quest System based on [shomykohai's Godot 4 quest system](https://github.com/shomykohai/quest-system)
* Lockpick Minigame adapted from code by [thelastflapjack](https://github.com/thelastflapjack) and [Hexadots](https://github.com/Hexadotz)
* FloatableBody / 3D fluid physics by [ueshita](https://github.com/ueshita/godot-floatable-body)
* [Godot State Charts by derkork + contributors](https://github.com/derkork/godot-statecharts)
