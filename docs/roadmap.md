# Daedalion roadmap

## 1.3.0

This release ships the Advanced player controller, public interaction actions, quickslot sets and views, elemental states for props and actors, and transactional JSON saves on Godot 4.7.2. See the [changelog](changelog.md) for release details and the [migration guide](migration-1.2-to-1.3.md) for existing projects.

## 1.4 plans

**Full multiplayer.** The plan is co-op with any number of players, with both a listen host and a dedicated server. Synchronization covers the whole world, including changes made away from a particular player. The host or dedicated server owns the saves.

**Gamepad support.** Planned work covers analog look, driving vehicles, sitting, navigating menus and using the quickslot wheel throughout gameplay.

These are plans for 1.4. There is no announced release date.
